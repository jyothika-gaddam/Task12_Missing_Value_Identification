# Task 12 - Missing Value Identification

## 📌 Project Overview

This project focuses on identifying and analyzing missing values in the Titanic dataset using Python and Pandas.

The goal is to understand which columns contain missing data, how many values are missing, and what percentage of the dataset is affected.

## 🎯 Objectives

- Identify missing values in the dataset
- Calculate the number of missing values for each column
- Calculate the percentage of missing values
- Summarize the missing-value patterns
- Understand why blindly removing missing data can be risky

## 🛠️ Tools & Technologies

- Python
- Pandas
- Jupyter Notebook
- VS Code
